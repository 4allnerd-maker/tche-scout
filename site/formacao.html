Formação

Escolha o time, a formação e os 11 jogadores. Cada jogador aparece com o card e o OVR; depois é só exportar a imagem.

Clique num jogador para trocar, colocar a foto ou abrir a ficha. Por enquanto só há dados de 2026; escalações de outras temporadas (ex.: campeões de 2024) entram quando a API for ligada.
